## 공개 전 확인

스크린샷을 추가하기 전에 다음을 확인합니다.

- 개인 Notion 원문이 과도하게 노출되지 않는가
- ChatGPT / Claude 실제 대화 원문이 포함되지 않는가
- private repository의 민감한 파일명·URL·branch 정보가 불필요하게 노출되지 않는가
- token, `.env`, credential, 이메일 등 식별/보안 정보가 없는가
- Showcase에서 설명할 제품 흐름에 필요한 정보만 남겼는가

원본 Evidence를 제품에서 다루더라도 **공개 Showcase에는 선별·비식별화된 화면만 사용**합니다.
